macaddr Reservation Service
============================

An authenticated HTTP microservice, companion to :doc:`/pihole_importer`,
that adds host reservations to ``macaddr.txt`` over the network instead of
by hand. See :doc:`architecture` for how it works, :doc:`how_to` to
install and call it, and :doc:`troubleshooting` for its error responses.
